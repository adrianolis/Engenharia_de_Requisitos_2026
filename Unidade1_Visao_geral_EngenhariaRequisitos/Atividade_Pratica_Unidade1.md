# Respostas – Atividade Prática (Sistema de Controle de Alunos)

**1. Quem utilizará o sistema?**
Secretaria, professores, coordenação, alunos e responsáveis.

**2. Requisitos funcionais:**
- Cadastrar e editar dados dos alunos.
- Registrar notas e frequência.
- Gerar boletim/relatório de desempenho.

**3. Requisitos não funcionais:**
- Controle de acesso por perfil de usuário (segurança).
- Sistema deve responder rápido às consultas (desempenho).

**4. Por que levantar os requisitos antes de desenvolver?**
Para evitar retrabalho e garantir que o sistema atenda ao que os usuários realmente precisam.
